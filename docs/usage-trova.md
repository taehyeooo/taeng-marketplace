# Trova에서의 사용 기록

## 왜 만들었나 (실측)
Trova 앱을 만들며 한 Claude Code 세션(2026-09-25 ~ 10-07)에서 디자인 확인에 쓴 명령을 세었다.

| 반복 작업 | 횟수 |
|---|---|
| 타입 검사(`tsc --noEmit`) | 268 |
| 시뮬레이터 화면 캡처 | 206 |
| 디자인 토큰 검사(`check:tokens`) | 84 |
| 글자 크기 바꾸기 | 34 |
| 캡처 픽셀 분석 | 8 |

## 첫 실사용 (2026-10-07)
| 시각 | 무엇 | 결과 |
|---|---|---|
| 18:40 | `design-sweep home` | 글자 크기 3단계 캡처 → 한 장, **약 10초**. 접근성 큰 글자에서 홈 '비 소식' 배너의 핵심 문장("실내 대안을 확인해보세요")이 …로 잘린 것을 발견 |
| 18:40 | `design-compare before/after` | 두 줄 제한을 풀고 고치기 전·후 비교 이미지 생성 |
| 18:40 | `after-edit-check` | 고친 파일로 타입·토큰 검사 2초, 통과 |
