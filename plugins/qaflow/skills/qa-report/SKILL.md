# QA 보고서 (qaflow)

`bash "${CLAUDE_PLUGIN_ROOT}/scripts/report.sh" [실행 기록]` → 마크다운 초안. "확인하지 못한 것"과 "찾은 문제" 표는 대화에서 채운다.
사용자에게는 짧게(무엇을 어디서 확인했는지, 문제, 남은 것), 문서로 남기라고 하면 이 초안과 캡처 묶음을 함께 넣는다.
