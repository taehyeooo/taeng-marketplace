# 화면 훑기 (uiflow)

`bash "${CLAUDE_PLUGIN_ROOT}/scripts/sweep.sh" <화면 이름> [--dark]` — 앱 레포 폴더에서 실행.

1. 확인할 화면을 QA 기기에 띄운다(로그인·데이터가 필요하면 devflow `qa-sim` 등으로 준비).
2. 실행 → 한 장짜리 이미지 경로가 나온다. 그 이미지를 읽어 확인한다.
3. 볼 것: 잘린 글자(… 처리로 숫자·핵심 단어가 사라지지 않았는지), 겹침, 빈 사각형처럼 그려지지 않은 요소, 버튼이 화면 밖으로 밀림, 터치 영역이 너무 작음.
4. 발견한 것은 "글자 크기 · 무엇이 · 어떻게" 로 사용자에게 보고하고, 고친 뒤 다시 훑어 같은 이미지로 확인한다.
끝나면 글자 크기는 보통(large)으로, 화면 모드는 라이트로 되돌아간다.
