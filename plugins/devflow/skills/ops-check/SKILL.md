# 운영 확인 (devflow)

`bash "${CLAUDE_PLUGIN_ROOT}/scripts/ops-check.sh"` (한 번) · `ops-check.sh --watch 10` (10분 동안 1분마다)
- 배포가 끝나면 `--watch 5` 정도로 지켜보고 결과를 보고한다.
- ✗ 항목은 값과 기준을 그대로 사용자에게 알리고, 원인을 보려면 로그를 더 읽는다(읽기만). 서버를 바꾸는 조치는 사용자에게 먼저 묻는다.
- 운영 DB는 읽기 쿼리만 둔다. 항목은 설정 `ops.checks`에 — 서비스마다 다르다.
