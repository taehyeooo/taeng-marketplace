# 이슈에서 머지까지 (devflow)

`bash "${CLAUDE_PLUGIN_ROOT}/scripts/ship.sh" <명령>`
1. 시작: `start <타입> <영문-슬러그> "<제목>" ["<이슈 본문>"]` → 이슈 번호·브랜치·작업 폴더가 나온다. 이후 작업은 그 폴더에서.
2. 커밋은 프로젝트 규칙대로(커밋 검사 훅이 확인). 기록은 `work-record`로 같은 브랜치에.
3. PR: 작업 폴더에서 `pr ["<본문에 더할 문장>"]` → 빌드·테스트 후 푸시, 커밋 목록·테스트 수·`Closes #번호`가 들어간 PR.
4. 머지는 사용자가 원할 때만: `merge [PR 번호]` → 설정 방식으로 머지, 이슈가 안 닫혔으면 닫고, 깨끗한 작업 폴더만 지우고(설정·무시 파일이 남았으면 지우지 않고 알림), `afterMerge`(예: 로컬 서버를 기준 커밋으로) 실행.
배포는 머지와 따로 `deploy`로 한다.
