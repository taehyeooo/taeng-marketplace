# 디자인 리뷰

화면 하나(또는 PR에서 바뀐 화면들)를 아래 순서로 본다. 기준은 이 문서와 레포의 디자인 결정(ADR·디자인 가이드가 있으면 그것)이다. 고치지 말고 먼저 **찾은 것만** 보고한다 — 사용자가 고치라고 하면 그때 고친다.

## 0. 대상 정하기
- 사용자가 파일·화면을 말하지 않았으면 `git diff --name-only origin/main...`에서 화면 파일(`.tsx`·`.jsx`·`.css`)을 고른다. 그래도 없으면 어느 화면인지 묻는다.
- 화면이 떠 있으면(개발 서버) 폰(390px)·태블릿(768px)·데스크톱(1280px) 폭, 밝은·어두운 모드 스크린숏을 찍어 같이 본다(열고, 찍고, 콘솔 오류 보기). 브라우저 도구가 있으면 그것으로, 없으면 playwright-core + 설치된 크롬(`chromium.launch({ channel: 'chrome' })`, 모드는 `newPage({ colorScheme })`)으로 짧은 스크립트를 레포 밖에 써서 돌린다. 스크린숏은 레포에 넣지 않는다. 상태가 바뀌는 화면(빈·로딩·오류)은 상태마다 찍는다. 못 띄우면 코드만 보고 "화면 확인 안 함"이라고 적는다.

## 1. 토큰만 썼나
- 레포에 디자인 토큰 검사 스크립트가 있으면 돌리고 결과의 `파일:줄`을 그대로 보고에 옮긴다. 없으면 아래를 눈으로 본다.
- 눈으로도 본다: 색 `#hex`·`rgb()`, Tailwind 임의 값(`text-[13px]`, `p-[7px]`, `bg-[#...]`), `style={{ ... }}`·`StyleSheet`의 숫자 크기·간격·모서리. 토큰 이름(역할: 배경·글자·강조 등)으로 바꾼다.
- 예외는 `토큰 예외: 이유` 주석이 있을 때만 통과.

## 2. 간격 리듬·정렬
- 간격이 토큰 단계 안에서 일정한가(같은 종류 요소 사이 간격이 같은가, 묶음 안 < 묶음 사이).
- 왼쪽 정렬선이 맞는가, 글자 기준선·아이콘 세로 가운데가 맞는가.
- 강조색은 좁은 용도(주 버튼·선택 상태·링크)에만 — 넓은 면에 쓰지 않는다.

## 3. 상태
- 데이터가 있는 화면마다 **빈 상태**(무엇이 없고 무엇을 하면 되나), **로딩**(스켈레톤 부품), **오류**(무엇이 왜 + 다시 하기)가 있나. 버튼은 누르는 중(비활성·진행 표시) 상태가 있나.
- 레포에 공통 부품(빈 상태·스켈레톤·토스트·대화상자)이 있으면 그것을 쓴다.

## 4. 대비
- 본문 글자/배경 **4.5:1 이상**, 큰 글자(24px 이상 또는 굵은 19px 이상)·아이콘 3:1 이상. 다크 모드 본문은 **7:1 목표**.
- 토큰 값으로 계산한다(상대 휘도 공식 — WCAG 2). 흐린 회색 글자, 강조색 위 흰 글자, 비활성 상태를 특히 본다.
- 오류 문장을 위험색 글자로 쓰면 다크에서 7:1 목표에 못 미치기 쉽다. 문장은 본문 색으로, 위험색은 짧은 표시·테두리·아이콘에.

## 5. 터치 영역
- 누르는 것(버튼·링크·아이콘 버튼·체크박스)은 **44×44px 이상**(눈에 보이는 크기가 작으면 여백으로 영역을 키운다). 누르는 것끼리 8px 이상 떨어졌나.

## 6. 다크 모드
- 다크에서 같은 역할 토큰을 쓰는가(밝은 모드 값 직접 쓰기 없음). 그림자 대신 면 밝기로 층을 나누는가. 이미지·로고가 어두운 배경에서 보이나.

## 7. 반응형
- 폰(390px)·태블릿(768px)·데스크톱(1280px)에서 가로 스크롤 없음, 글자가 잘리지 않음, 고정 폭 컨테이너 없음. 표는 폰에서 카드나 가로 스크롤 영역으로.

## 8. 한글 줄바꿈
- 본문·제목에 `word-break: keep-all`(Tailwind `break-keep`)이 있나 — 없으면 단어 중간에서 끊긴다. 긴 영문·URL은 `overflow-wrap: anywhere`.
- 앱(React Native)은 줄바꿈 규칙이 다르다 — 화면으로 확인하고, 안 되면 문구를 줄이는 쪽으로.

## 보고 형식
찾은 것을 심각한 순서(대비·터치·상태 > 토큰 > 정렬·간격)로, 한 줄에 하나씩:

```
src/app/login/page.tsx:42 — 버튼 글자 #9CA3AF가 흰 배경에서 2.5:1 — text-fg-muted 대신 text-fg 토큰
src/app/login/page.tsx:58 — 로딩 상태 없음(제출 중에도 버튼이 눌림) — 제출 중 disabled + 진행 표시
```

끝에 한 줄로: 본 화면·폭·모드, 돌린 검사(토큰 검사·스크린숏), 확인하지 못한 것.
