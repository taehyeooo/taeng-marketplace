# 러스트 규칙

러스트 파일을 읽거나 고칠 때 Claude Code가 자동으로 읽는다(ADR(경로별 규칙)). 목록은 [CLAUDE.md](../../CLAUDE.md) "경로별 규칙".

- **커밋 전**: `sh scripts/check_rust.sh` — 레포 안 cargo 프로젝트마다 `cargo fmt --check`·`cargo clippy --all-targets -- -D warnings`(경고도 실패)·`cargo test`. CI `rust`가 러스트 파일이 바뀐 PR에서 같은 것을 돌린다.
- **테스트 먼저**: 테스트를 먼저 쓰고 실패를 확인한 뒤 구현한다. 일부러 망가뜨려(변형) 테스트가 잡는지 본다.
- **에러**: 테스트가 아닌 코드에서 `unwrap()`·`expect()`·`panic!`을 쓰지 않는다 — `Result`와 `?`로 올리고, 사용자에게 보이는 곳(HTTP 응답·CLI 출력)에서 무엇이 왜 잘못됐는지 한국어로 바꾼다.
- **빌드 결과**: `target/`은 커밋하지 않는다(`.gitignore`). 실행 파일을 만드는 프로젝트는 `Cargo.lock`을 커밋한다.
- **의존성**: 필요한 크레이트만, 라이선스(MIT·Apache-2.0 등)를 확인한다. 유료 서비스 SDK를 기본으로 넣지 않는다(ADR(비용 0원)).
- **다른 서버와 같이 쓸 때**(예: 자바·노드 서버 + 러스트 계산 작업자): 사용자 요청·로그인은 앞 서버가 받고, 러스트는 같은 서버 안 `127.0.0.1`에서만 연다(`0.0.0.0` 금지). 처음부터 나누지 말고, 앞 서버로 먼저 만든 뒤 느린 부분을 숫자로 재서 그 부분만 뗀다(ADR(샘플 먼저)). 주고받기는 HTTP + JSON(axum + serde)으로 시작하고, 오래 걸리는 일은 접수 → 나중에 결과.
- **설명 주석**: 공개 함수 위에 한국어 한 줄 `///`(무엇을 하나).
